# 마켓 모니터

한국·미국 지수, 선물, 유가, VIX와 미국 10년 국채금리 및 SK하이닉스 ADR 등 13개 항목을 한 화면에서 확인합니다.

페이지: https://today8934.github.io/market-live/

## 갱신 방식

- 12개 지표: 페이지를 열어 두면 시세 중계 서버에 60초마다 직접 조회합니다. 새로고침 버튼도 중계 서버를 조회하며 GitHub 예약 실행을 기다리지 않습니다. 중복 조회 결과는 최대 60초간 공유합니다.
- 시세 중계: https://market-live-feed-8934.silverpearl6.chatgpt.site/api/quotes?v=3 (공개 시세 전용, 읽기 전용). 서버 소스는 Sites 프로젝트 appgprj_6ae9dd91a7288191a30793770c26a903에서 관리합니다.
- GitHub Actions의 수집·배포는 첫 화면에 표시할 저장 시세와 페이지 변경 배포용입니다. 예약이 늦어져도 열린 페이지의 직접 조회는 계속됩니다.
- US TECH 100: FOREX.com 나스닥100 현금 CFD의 TradingView 공식 위젯입니다. 위젯이 자체 갱신하며 다른 제공처의 US TECH 100 가격과 다를 수 있습니다.
- 무료 공개 시세에는 공급자 지연이 있습니다. 60초마다 조회해도 초 단위 실시간 서비스가 되지는 않습니다.
- 상단 수집 시각과 카드별 시세 기준 시각을 구분하여 한국시간으로 표시합니다.
- 수집 실패 시 이전 값과 원래 시각을 유지합니다. 수집이 3분 이상 멈추면 장 마감 상태 대신 갱신 지연을 표시합니다. 전체 수집 실패 시 기존 배포를 보존합니다.
- GitHub는 공개 저장소에서 60일간 활동이 없으면 예약 작업을 중지할 수 있습니다. Actions의 실행 기록을 확인하고 필요 시 Enable workflow를 실행하세요.

## 차트 기간

- 시장 탭 위의 기간 선택으로 해당 탭의 차트를 함께 바꾸거나 카드·상세 화면에서 지표별로 선택할 수 있습니다. 브라우저에 선택을 저장하며 자동 갱신 후에도 유지합니다.
- 1일: 최근 거래일 5분 간격. 5일: 최근 5거래일 15분 간격. 1·3·6개월과 1년: 일별 시세. 5년: 주별 시세. 장기 차트 X축에는 날짜와 연도를 표시합니다. 진행 중인 거래일·주간의 값은 이후 바뀔 수 있습니다.
- 큰 숫자는 최신 시세이며, 등락폭·등락률은 선택 기간에 따라 바뀝니다. 1일은 검증된 전일 종가 대비, 5일 이상은 차트의 첫 유효 시세 대비 최신 시세입니다. 5일은 첫 15분봉, 1개월~1년은 첫 일봉, 5년은 첫 주봉의 종가를 기준으로 사용하며 상세 화면에 기준값·시점을 표시합니다. 기간 데이터가 없으면 일일 등락을 대신 표시하지 않습니다. 차트 선 색은 해당 기간에 표시한 등락과 같습니다. US TECH 100 위젯의 등락은 위젯에서 선택한 기간 기준입니다.
- 야간선물은 현재 제공처의 최근 야간장 안에서 전체·최근 1·3·6시간을 선택합니다. 전체 등락은 주간 종가 대비, 최근 1·3·6시간 등락은 해당 구간 첫 시세 대비입니다. 장기 이력으로 대체하거나 다른 지수와 섞지 않습니다.
- US TECH 100은 동일한 FOREX.com CFD의 TradingView 차트 위젯 하단에서 기간을 선택합니다.
- 기간별 데이터는 중계 서버의 `/api/history?id=sox&range=1mo`처럼 알려진 지표·기간만 조회합니다. 5일 차트는 60초, 장기 차트는 5분 동안 공유하며 요청 실패 시 동일 기간의 기존 차트만 유지합니다.

## 시세 제공처

국채금리는 % 단위, 변화는 %p와 bp로 표시합니다. 나스닥 종합·나스닥100 선물·US TECH 100 CFD를 구분합니다.

## 프리·애프터 및 야간 시세

- SK하이닉스 ADR(SKHY)은 정규장 가격과 차트를 달러로 표시합니다. 프리마켓과 애프터마켓은 각각 최근 거래값과 직전 정규장 종가, 한국시간을 표시합니다. 자세히 화면에서 세션별 차트도 볼 수 있습니다.

- 미국 현물지수 아래에 별도 추종 ETF 참고 시세를 표시합니다: 나스닥 종합 ONEQ, S&P 500 SPY, 반도체 지수 SOXQ. 지수 값·차트와 섞지 않습니다.
- ETF의 실제 거래 세션 시간표로 프리/애프터를 분류하고, 직전 정규장 종가와 비교합니다. 지난 세션·수집 실패·지연을 구분하며 원래 시세 시각을 유지합니다.
- Yahoo 차트 요청은 제공되는 확장시간 데이터도 포함합니다. 선물·유가는 전자거래 세션, 야간선물은 야간장, US TECH 100은 CFD 세션을 사용합니다.
- VIX는 정규/확장 산출시간을 구분합니다. 코스피·코스닥과 Cboe TNX에는 별도 프리/애프터 시세를 만들어 넣지 않습니다.
- 브렌트 BZ=F는 NYMEX Brent Last Day Financial 선물입니다.
